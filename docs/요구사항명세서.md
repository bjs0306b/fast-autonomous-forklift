# 지게차 프로젝트 요구사항 명세서

> 이 문서는 **Jira 계층(Epic → Story → Task)** 과 **스프린트**에 그대로 매핑되도록 작성한다.
> 채워진 내용을 기준으로 스프린트/에픽/스토리/태스크를 자동 생성한다.
>
> - **프로젝트 키**: `S15P11A304`
> - **작성 규칙**: 아래 표의 형식을 유지할 것 (표를 그대로 읽어 Jira 이슈로 변환함)
> - **우선순위**: `Highest / High / Medium / Low`
> - **상태**: `To Do` (신규 생성 시 기본값)

## 1. 프로젝트 개요

### 배경 / 문제 정의
- 화물 센터에서 지게차 운영은 **위험**하여 여러 대를 동시에 운영하기 어렵다.
- 사람이 직접 운전하는 구조라 인력 의존도와 사고 위험이 크다.

### 목표
- 사람을 배제하고 **지게차가 스스로 화물 적재를 수행하는 AIoT 시스템**을 구축한다.
- 무인화로 위험 요소를 제거하여 **여러 대의 지게차를 동시에 운영**할 수 있게 한다.

### 핵심 아이디어
- 화물 적재(인식·판단)는 **Jetson Orin Nano**를 이용해 처리한다.
- 다대(多臺) 지게차 협업 운영을 전제로 설계한다.

| 항목 | 내용 |
|------|------|
| 프로젝트명 | 무인 자율 지게차 AIoT 프로젝트 |
| 목표 | 무인 자율 지게차로 화물 적재를 자동화하고 다대 동시 운영을 실현 |
| 기간 | YYYY-MM-DD ~ YYYY-MM-DD |
| 핵심 하드웨어 | Jetson Orin Nano, 리니어 스텝 모터, 모터 제한 스위치, (추가) |
| 기술 스택 | 임베디드: / 백엔드: / 프론트: / 통신: / AI(비전): |
| 팀 구성 | (역할별 담당) |

> ⏳ 아래 요구사항(Epic/Story) 상세는 추가 내용 수신 후 채운다. (현재는 개요/배경까지만 기록)

## 4. 요구사항 (Epic → Story → Task)

> **Epic** = 큰 기능 덩어리, **Story** = 사용자/기능 단위, **Task** = 스토리 하위 작업.
> 각 Story 행이 Jira Story 이슈 1개가 된다. `담당 Epic`, `Sprint`, `우선순위`를 반드시 채울 것.
