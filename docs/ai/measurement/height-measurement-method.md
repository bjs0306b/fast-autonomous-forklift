# 높이 측정 방식 정의

RTMDet으로 팔레트 위 적재 상자의 영역을 검출한다.

검출된 상자 바운딩박스 중 최상단과 최하단 좌표를 이용해
사진상의 적재 높이를 픽셀 단위로 계산한다.

TF-NOVA LiDAR로 적재물 전면까지의 거리를 측정한다.
거리값을 사용하면 상자가 팔레트의 앞쪽이나 뒤쪽에 놓였을 때
발생하는 픽셀 크기 차이를 보정할 수 있다.

카메라의 세로 방향 초점거리 `fy`와 TF-NOVA 거리값을 이용하여
팔레트 상판부터 적재물 최상단까지의 실제 높이를 산출한다.

깊이는 측정하지 않으므로 실제 용적을 계산하지 않고,
용적 근사를 위한 적재 높이만 산출한다.
