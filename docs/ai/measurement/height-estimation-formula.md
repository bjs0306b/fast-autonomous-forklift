# 높이 산출 공식

RTMDet으로 검출한 적재 상자 영역에서 최상단과 최하단의
픽셀 좌표를 이용해 픽셀 높이를 계산한다.

## 계산식

```text
픽셀 높이(px) = 최하단 y 좌표 - 최상단 y 좌표

적재 높이(cm) =
    픽셀 높이(px) × LiDAR 거리(cm) / 카메라 세로 초점거리(px)
```

현재 Logitech BRIO 100의 세로 초점거리는 다음 값을 사용한다.

```text
fy = 2039.07 px
```

예를 들어 픽셀 높이가 600 px이고 LiDAR 거리가 100 cm이면 다음과 같다.

```text
적재 높이 = 600 × 100 / 2039.07
          ≈ 29.43 cm
```

깊이를 측정하지 않으므로 실제 용적은 계산하지 않고
팔레트 위 적재물의 높이만 산출한다.
