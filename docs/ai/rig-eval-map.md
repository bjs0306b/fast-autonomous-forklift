# 리그 평가셋 mAP 측정 (S15P11A304-148)

스테이션 박스 인식 KPI(**mAP@0.5 ≥ 92%**)를 판정한 기록. 판정 무대는 공개셋이 아니라
**실물 리그 평가셋**이다 (2026-07-23 결정, 명세 MR !46).

- 촬영: 2026-07-27, `ai/data/raw/rig/eval_20260727` 112장, 리그 정면 약 200cm
- 모델: exp7(증강) ONNX `ai/models/end2end.onnx` @800
- 도구: `dataset/eval_map.py` (COCO all-point interpolation, IoU 0.5)

## 결과

정답셋을 두 가지로 만들어 같은 30장을 채점했다.

| 정답셋 | mAP@0.5 | box AP | pallet AP |
|---|---|---|---|
| clean — exp7 프리라벨을 사람이 손본 것 | **1.0000** | 1.0000 | 1.0000 |
| **independent — 사람이 빈 화면에서 그린 것** | **0.9842** | 0.9727 (GT 112) | 0.9957 (GT 30) |

**KPI 92% 통과** (독립 라벨 기준 98.4%).

### 왜 정답셋을 두 번 만들었나

처음 112장은 exp7 예측을 프리라벨로 깔고 사람이 검수하는 방식으로 만들었다. 이 정답으로
exp7을 채점하면 **자기 예측을 자기 정답으로 쓰는 것**이라 점수가 부풀려진다. 실제로 위
표에서 clean 정답은 **정확히 1.0000**이 나왔다 — 틀릴 수가 없는 구조였다는 증거다.

그래서 30장을 계층 추출(박스 개수 0 / 1~2 / 3~4 / 5개+)해 `dataset/make_independent.py`로
**라벨을 비운 뒤**, `dataset/review_labels.py`로 처음부터 그렸다(142개 전부 수작업).
오염에 의한 부풀림은 **+1.58pp**로 측정됐다.

30장 중 7장(0009 0028 0033 0038 0087 0092 0107)에서 사람과 exp7의 박스 개수가 갈렸다 —
적층 박스를 몇 개로 세느냐의 차이가 대부분이다.

## 운영 임계

독립 라벨 기준, 임계별 정밀도/재현율:

| 임계 | box | pallet |
|---|---|---|
| 0.40 | 91.5% / 96.4% | **96.8% / 100%** |
| 0.50 | 93.9% / 95.5% | 96.7% / 96.7% |
| 0.60 | 96.3% / 93.8% | 96.3% / 86.7% |

**파렛트는 0.4, 박스는 0.5** 권고. exp6 때 남긴 "파렛트 임계 0.5→0.4~0.45" 메모가 실측으로
확인됐다 — 0.4에서 파렛트 재현율 100%(30/30), 0.5면 1개를 놓친다.

## 파렛트 bbox 규약

학습셋(rig 273개)과 같아야 한다. 다르게 그으면 IoU가 깎여 멀쩡히 잡은 파렛트가 미검출로
집계된다.

- **위** — 상판 격자 데크의 가장 안쪽(먼) 모서리. 앞면 밴드만 치면 안 된다.
- **아래** — 다리 밑단, 바닥 접지선
- **좌우** — 데크 양 끝 (박스가 가려도 파렛트 실제 끝까지)

검증 지표: 파렛트 높이가 프레임 높이의 **13~21%**. 학습셋 평균 18.0%, 독립 라벨 중앙 16.8%.
8% 근처가 나오면 상판이 빠진 것이다.

## 한계

GT 142개(박스 112·파렛트 30)는 KPI 판정 표본으로는 작다 — 박스 미검출 1건이 mAP를 약 1pp
흔든다. 나머지 82장은 오염된 정답만 있어 이 수치에 포함하지 않았다. 같은 리그·같은 조건이라
결론이 뒤집힐 여지는 크지 않다고 보지만, 표본을 늘리려면 나머지도 독립 라벨링이 필요하다.
